# First run — personal wiki bootstrap

Read this only when `personal-template/AGENTS.md` sends you here. Work in the NEW, empty folder the user gave you as the working directory — never write into the shared wiki's `personal-template/`. Copy files with copy commands (`cp`, `Copy-Item`), never by re-typing their content.

1. **Resolve the shared wiki.** You were handed the path to `<shared>/personal-template/AGENTS.md`; the shared wiki's root `<shared>` is two levels up. Check it's reachable and its `AGENTS.md` says `mode: shared`; if not (drive not mounted, wrong path), stop and tell the user. Read its frontmatter `project` and `link_style` and its **About this wiki** line — if they differ from the template's, trust the shared wiki.
2. **Find Python.** Try `python3 --version`, `python --version`, `py --version`; the first reporting Python 3.8+ is `<python>`, else `none` (tell the user the tools need Python 3; everything still works by hand, with more tokens).
3. **Questions — who am I talking with?** Ask: (a) **full name**, written `Lastname Firstname` in every `history` entry (ask if the split is ambiguous); (b) a **nickname**; (c) the **local path of a related code repo**, or `none`; (d) whether new pages default to **a)** `public: true` (shared on the next Push) or **b)** `public: false` (stays here until flipped). You may draft (a)/(b) from context (e.g. `git config user.name`) as a proposal to confirm. Project and link style are fixed by the shared wiki — don't ask.
4. **Copy the machinery** into the new folder:
   - `<shared>/personal-template/AGENTS.md` → `AGENTS.md`, `<shared>/personal-template/schema/sync.md` → `schema/sync.md`
   - `<shared>/schema/lock.md`, `lint.md`, `maintain.md` → `schema/`
   - `<shared>/tools/wiki.py` → `tools/wiki.py`
5. **Lock** the new wiki: generate a session id and run `<python> tools/wiki.py lock acquire --op init --session <id>` (no Python: `schema/lock.md`). Hold it until step 9.
6. **Personalize `AGENTS.md`** with targeted edits: fill `{{FULL_NAME}}`, `{{NICKNAME}}`, `{{REPO_PATH_OR_NONE}}`, `{{DEFAULT_PUBLIC}}` from step 3, `{{PYTHON_COMMAND}}` from step 2, any remaining `{{…}}` from the shared wiki (project, link style, About line), `created`/`modified` = today. Delete the `TEMPLATE FILE` comment and everything from the `template-only` marker comment through its `/template-only` closing comment. It is now an independent personal schema.
7. **Scaffold:** `CLAUDE.md` — copy the shared wiki's `CLAUDE.md` (a pointer whose `@AGENTS.md` line makes Claude Code load the schema); `wiki-shared-link.md` — frontmatter `type: shared-link` and `shared_wiki_path: <shared>`, plus a line saying the path is specific to this machine; `index.md` (heading + empty `## Parties`, `## Entities`, `## Concepts`); `wiki-maintenance.md` (`## Open tasks`, `## Log`); folders `raw/`, `log/`, `wiki/parties/`, `wiki/entities/`, `wiki/concepts/`, `wiki/summaries/`, `wiki/assets/`.
8. **Pull everything:** run Pull from `schema/sync.md` in full against `<shared>` — every shared page is copied in with `public: true`. This is joining the project already in progress; skip nothing (schema propagation is a no-op, the versions already match).
9. **Log and release:** `<python> tools/wiki.py log init "<project> (bootstrapped from personal-template, pulled <n> pages)"`, run `check` once, then `lock release --session <id>`.
