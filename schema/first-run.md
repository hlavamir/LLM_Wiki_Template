# First run — bootstrap & setup

Read this only when `AGENTS.md` sends you here (no `index.md` or `wiki/` yet). Do the steps in order. This file deletes itself at the end — a running wiki never needs it again.

1. **Find Python.** Try `python3 --version`, `python --version`, `py --version`; the first that reports Python 3.8+ is `<python>`. None works → `<python>` is `none`: tell the user `tools/wiki.py` (checks, log, lint scoping, transcript capture, locking) needs Python 3, and that everything still works by hand, just with more tokens.
2. **Lock.** Generate a session id (any random string, e.g. a GUID) and run `<python> tools/wiki.py lock acquire --op init --session <id>` (no Python: `schema/lock.md`). Hold it until step 10.
3. **Scaffold** next to `AGENTS.md`: `index.md` (a `# <project> — Index` heading and empty `## Parties`, `## Entities`, `## Concepts` sections), `wiki-maintenance.md` (`## Open tasks` and `## Log`), and the folders `raw/`, `log/`, `wiki/parties/`, `wiki/entities/`, `wiki/concepts/`, `wiki/summaries/`, `wiki/assets/` (a `.gitkeep` in each empty one).
4. **Question 1 — who am I talking with?** Ask for (a) the **full name**, written `Lastname Firstname` in every `history` entry (ask if the split is ambiguous), (b) a **nickname**, (c) the **local path of a related code repository**, or `none`. You may draft (a)/(b) from context (e.g. `git config user.name`), as a proposal to confirm, never as fact.
5. **Question 2 — name & description.** From the folder name, a README/manifest, the git remote, top-level files, draft a project **name** and one-line **description**, and offer: **a)** use these **b)** write your own.
6. **Question 3 — just you, or several people?** **a)** just me — one local wiki → `mode: solo`. **b)** shared — a synced wiki several people maintain → `mode: shared`. Shared means this folder must sit on storage every collaborator reaches and that syncs (a Google Shared Drive, OneDrive/SharePoint, Dropbox, a network share) — confirm it does, and mention that `wiki.lock` is only advisory on synced storage. Each person then keeps a personal wiki of their own (step 9). Unsure → suggest solo; moving to shared later is manual work.
7. **Question 4 — how will the wiki be viewed?** **a)** Obsidian only → `link_style: wikilinks`. **b)** GitHub / a plain browser → `markdown`. **c)** both → `markdown`. In shared mode personal wikis inherit this and never ask.
8. **Personalize `AGENTS.md`** with targeted edits: `project`, **About this wiki**, `mode`, `link_style`, `python`, and `created`/`modified` = today. Solo: fill `owner_name`, `owner_nickname`, `repo_path`. Shared: delete those three lines — the schema belongs to the team. Then prune:
   - Delete everything from the `template-only` marker comment through its `/template-only` closing comment (the bootstrap and first-run sections), and the `TEMPLATE FILE` comment at the top.
   - Spans fenced by `shared-only` / `solo-only` marker comments (closed by `/shared-only` / `/solo-only`; inline or whole blocks): for the chosen mode delete only the two markers; for the other mode delete the markers and everything between them. No marker comments may remain.
   - **Solo:** delete `schema/shared.md` and the `personal-template/` folder, and remove their two lines from the Layout tree.
9. **Shared only — prepare `personal-template/`.** If the folder is missing (only some files were copied), download it from the source you bootstrapped from, else from `hlavamir/LLM_Wiki_Template` on `main` (`personal-template/AGENTS.md`, `README.md`, `schema/first-run.md`, `schema/sync.md`); no network → ask the user to copy it in, never invent it. In `personal-template/AGENTS.md` replace `{{PROJECT_NAME}}`, `{{PROJECT_ONE_LINE}}` and `{{wikilinks|markdown}}` with this wiki's values; leave the other `{{…}}` placeholders — each person's first run fills those. Tell the user how people join: send each collaborator to `personal-template/README.md`; the user who set this up needs a personal wiki too, in a *separate* local folder.
10. **Log, verify, release.** `<python> tools/wiki.py log init "<project name>"` (shared: `"<project name> (shared, set up by Lastname Firstname)"`); run `<python> tools/wiki.py check` — a fresh wiki reports nothing but the lock you hold; then `lock release --session <id>`. Finally delete this file, `schema/first-run.md`.
